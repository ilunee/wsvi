# WSVI — 여성 암검진 취약성 복합지표 개발과 타당도 검증

전국 229개 시군구의 유방암·자궁경부암 검진 취약성을 접근성·수검률·수요·결과 4개 차원으로 측정하는 복합지표(Women's Screening Vulnerability Index)를 개발하고 검증한 개인 연구입니다.

- 유형: 개인 연구 (논문 형식 원고, 미투고)
- 기간: 2025.01 – 2026.01
- 도구: Python 3.11 (pandas, scipy, statsmodels, geopandas, matplotlib)
